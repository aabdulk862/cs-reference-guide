# Infrastructure Security

Securing the network, cryptographic foundations, and container runtime environments that applications depend on.

## Learning Path

1. [Cryptography Fundamentals](./cryptography-fundamentals.md) — Symmetric/asymmetric encryption, hashing, digital signatures, and key management
2. [Network Security](./network-security.md) — Firewalls, VPNs, zero-trust architecture, and DDoS mitigation
3. [Container Security](./container-security.md) — Image scanning, runtime policies, supply chain security, and pod security
