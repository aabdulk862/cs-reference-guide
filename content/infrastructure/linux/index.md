# Linux

Linux is the dominant operating system for servers, containers, cloud infrastructure, and embedded systems. Mastering Linux fundamentals and administration is essential for any engineer who deploys, debugs, or operates production systems — from writing Dockerfiles and configuring CI pipelines to diagnosing production outages over SSH.

This learning path starts with essential concepts and commands, then progresses into production-grade system administration.

## Learning Path

1. [Linux Essentials](./linux-essentials.md) — Filesystem hierarchy, process management, permissions, networking stack, and shell scripting fundamentals
2. [Linux Administration](./linux-administration.md) — System configuration, service management, user administration, storage, and operational best practices
