# Git

Git is the industry-standard distributed version control system used by virtually every software team. Understanding Git deeply — from its internal object model through advanced branching strategies and collaboration workflows — is essential for productive software development. This guide covers Git from fundamentals through advanced usage patterns used in professional environments.

## Learning Path

1. [What is Git](./what-is-git.md) — Core concepts, architecture, and the Git object model
2. [Git Commands](./commands.md) — Essential and advanced commands for daily workflows
3. [Git Branching](./branching.md) — Branching strategies, rebasing, and branch management
4. [Local vs Remote Repository](./local-vs-remote.md) — Remote operations, fetch vs pull, and multi-remote setups
5. [Merge Conflicts](./merge-conflicts.md) — Conflict resolution strategies and tools
6. [Pull Requests](./pull-requests.md) — Code review workflows, PR best practices, and CI integration
7. [.gitignore](./gitignore.md) — Ignore patterns, global gitignore, and common templates
