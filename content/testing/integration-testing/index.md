# Integration Testing

Integration testing verifies that components work together correctly, catching issues that unit tests miss at the boundaries between systems, services, and data stores.

## Learning Path

1. [Integration Testing](./integration-testing.md) — API testing, database testing, contract testing, and end-to-end strategies
2. [API & Contract Testing](./api-and-contract-testing.md) — REST/GraphQL/gRPC testing, Pact contracts, OpenAPI validation, and service virtualization
3. [Database Integration Testing](./database-testing.md) — Testcontainers, migration testing, fixture management, and repository testing patterns
4. [Database & E2E Testing](./database-and-e2e.md) — Testcontainers, Playwright/Cypress E2E, visual regression testing, and Page Object Model
