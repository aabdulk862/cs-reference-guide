# Unit Testing

Unit testing is the foundation of software quality, providing fast feedback on individual components and enabling confident refactoring. Combined with effective mocking strategies, unit tests form the base of the testing pyramid.

## Learning Path

1. [Unit Testing](./unit-testing.md) — Test structure, assertions, test doubles, TDD, and framework-specific patterns
2. [Mocking Strategies](./mocking-strategies.md) — Stubs, spies, fakes, dependency injection for testability, and when to mock
