# Next.js

Next.js is the React meta-framework for production, providing server-side rendering, static generation, API routes, and a powerful developer experience for building full-stack web applications.

1. [Next.js Overview](./nextjs.md) — SSR, SSG, ISR, API routes, and deployment strategies
