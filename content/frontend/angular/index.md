# Angular

Angular is Google's TypeScript-based component framework for building enterprise-scale single-page applications with dependency injection, RxJS, and a comprehensive CLI toolchain.

## Learning Path

1. [Angular Overview](./angular.md) — Components, services, dependency injection, routing, RxJS, and enterprise patterns
2. [Components & Templates](./components-and-templates.md) — Lifecycle hooks, change detection, content projection, directives, pipes, and standalone components
3. [Services & Dependency Injection](./services-and-di.md) — Hierarchical injectors, providers, HttpClient, interceptors, and RxJS state management
4. [Routing & Modules](./routing-and-modules.md) — Lazy loading, route guards, preloading strategies, NgModules vs standalone architecture
5. [RxJS & Reactive Patterns](./rxjs-and-reactive.md) — Observables, operators, Subjects, async pipe, error handling, and real-time data streams
