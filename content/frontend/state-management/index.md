# State Management

State management is one of the most critical architectural decisions in frontend applications. As applications grow in complexity, managing shared state across components becomes challenging. This guide covers the spectrum from Redux (the established standard) through modern lightweight alternatives that offer different tradeoffs in terms of boilerplate, performance, and developer experience.

## Learning Path

1. [Redux & Redux Toolkit](./redux.md) — Predictable state container with middleware, selectors, and RTK Query
2. [Redux Patterns](./redux-patterns.md) — Redux core concepts, Redux Toolkit, RTK Query, middleware, and normalized state
3. [Zustand & Lightweight Alternatives](./zustand.md) — Minimal state management with Zustand, Jotai, and Valtio
4. [Modern Alternatives](./modern-alternatives.md) — Zustand, Jotai, Recoil, Valtio, and signals-based state management
