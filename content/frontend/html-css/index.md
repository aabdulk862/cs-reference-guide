# HTML & CSS

HTML and CSS are the foundational technologies of the web. Mastering semantic markup, modern layout systems, and advanced CSS features is essential for building accessible, performant, and maintainable user interfaces.

## Learning Path

1. [HTML & CSS Fundamentals](./html-css.md) — Semantic markup, document structure, and core styling with modern layout techniques
2. [Modern CSS](./modern-css.md) — Flexbox, Grid, custom properties, container queries, cascade layers, and advanced selectors
