# Systems & I/O

File systems, concurrency primitives, and I/O scheduling determine how operating systems manage persistent storage, coordinate parallel execution, and handle device communication.

## Learning Path

1. [File Systems](./file-systems.md) — File system design, journaling, inodes, and storage abstractions
2. [Concurrency Primitives](./concurrency-primitives.md) — Mutexes, semaphores, condition variables, and lock-free programming
3. [I/O and Scheduling](./io-and-scheduling.md) — I/O models, disk scheduling, and process scheduling algorithms
