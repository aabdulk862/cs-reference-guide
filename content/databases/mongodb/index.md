# MongoDB

MongoDB is the leading document database for modern applications, offering flexible schemas, horizontal scalability, and a powerful aggregation framework.

## Learning Path

1. [MongoDB and Document Databases](./mongodb.md) — Document modeling, aggregation pipelines, indexing strategies, and replica sets
2. [Schema Design](./schema-design.md) — Document modeling patterns (embedding vs referencing), schema versioning, polymorphic pattern, bucket pattern, and outlier pattern
3. [Operations and Scaling](./operations-and-scaling.md) — Sharding strategies, replica set operations, backup/restore, monitoring, Atlas features, and change streams
