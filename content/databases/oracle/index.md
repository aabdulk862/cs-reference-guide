# Oracle Database

Oracle Database is the industry-leading enterprise relational database, powering mission-critical workloads with extreme availability, advanced diagnostics, and comprehensive tooling.

## Learning Path

1. [Oracle Database](./oracle-database.md) — PL/SQL, RAC, Data Guard, flashback technology, AWR/ASH diagnostics, and partitioning
2. [Performance Diagnostics](./performance-diagnostics.md) — AWR, ASH, ADDM, SQL Tuning Advisor, execution plans, optimizer hints, and wait events
3. [High Availability](./high-availability.md) — RAC architecture, Data Guard (physical/logical standby), switchover/failover, and GoldenGate replication
