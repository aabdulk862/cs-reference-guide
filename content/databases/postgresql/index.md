# PostgreSQL

PostgreSQL is the world's most advanced open-source relational database, offering extensibility, standards compliance, and enterprise-grade features for modern applications.

## Learning Path

1. [PostgreSQL Deep Dive](./postgresql.md) — MVCC, advanced indexing, JSONB, partitioning, replication, and connection pooling
2. [Replication and High Availability](./replication-and-ha.md) — Streaming replication, logical replication, Patroni, PgBouncer connection pooling, and failover strategies
3. [Performance Tuning](./performance-tuning.md) — EXPLAIN ANALYZE, index strategies (B-tree, GIN, GiST, BRIN), query optimization, vacuum tuning, and pg_stat_statements
4. [Advanced Features](./advanced-features.md) — JSONB operations, full-text search, partitioning, CTEs, window functions, and extensions (PostGIS, pg_cron, TimescaleDB)
