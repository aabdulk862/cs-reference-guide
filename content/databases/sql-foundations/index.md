# SQL Foundations

Core database concepts that apply across all relational database systems. These fundamentals form the foundation for working with any SQL database vendor.

## Learning Path

1. [SQL Fundamentals](./sql-fundamentals.md) — Joins, subqueries, CTEs, window functions, and stored procedures
2. [SQL Performance Tuning](./sql-performance-tuning.md) — Query plan analysis, indexing strategies, and optimization techniques
3. [Database Design Patterns](./database-design-patterns.md) — Schema design, normalization, denormalization, and data modeling
4. [Transactions and Consistency](./transactions-and-consistency.md) — ACID properties, isolation levels, and distributed transactions
