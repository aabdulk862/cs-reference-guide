# Network Protocols

Core network protocols that power the internet — from transport-layer reliability to application-layer communication and security.

## Learning Path

1. [TCP/IP](./tcp-ip.md) — Transport and internet layer protocols, connection management, and flow control
2. [DNS](./dns.md) — Domain name resolution, record types, caching, and DNS security
3. [HTTP](./http.md) — HTTP/1.1, HTTP/2, HTTP/3, methods, headers, and caching
4. [TLS & mTLS](./tls-mtls.md) — Transport layer security, certificate management, and mutual authentication
