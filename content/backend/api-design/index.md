# API Design

API design is a critical skill for backend engineers, encompassing REST, GraphQL, and gRPC paradigms. Each approach offers different trade-offs in terms of flexibility, performance, type safety, and developer experience. Modern systems often use multiple API styles — REST for public-facing APIs, GraphQL for flexible client queries, and gRPC for high-performance internal service communication. Understanding when and how to apply each paradigm is essential for building scalable, maintainable distributed systems.

## Learning Path

1. [REST API Design](./rest-api-design.md) — RESTful principles, resource modeling, versioning, pagination, and HATEOAS
2. [GraphQL](./graphql.md) — Schema design, resolvers, subscriptions, federation, and performance optimization
3. [gRPC](./grpc.md) — Protocol Buffers, streaming patterns, service mesh integration, and load balancing
