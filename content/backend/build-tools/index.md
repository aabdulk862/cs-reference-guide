# Build Tools

Build tools automate the compilation, testing, packaging, and dependency management of Java/JVM projects. Understanding Maven and Gradle deeply is essential for managing complex multi-module projects, optimizing CI/CD build times, and resolving dependency conflicts in production systems.

## Learning Path

1. [Maven](./maven.md) — Project Object Model, lifecycle phases, dependency management, and multi-module builds
2. [Gradle](./gradle.md) — Groovy/Kotlin DSL, task graph, incremental builds, and build cache optimization
