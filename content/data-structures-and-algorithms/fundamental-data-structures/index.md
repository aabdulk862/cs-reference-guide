# Fundamental Data Structures

Understanding core data structures is the foundation of computer science and software engineering. Each data structure offers different trade-offs in terms of time complexity, space usage, and operational characteristics. Mastering these fundamentals enables you to choose the right tool for any problem and reason about algorithmic performance in interviews and production systems.

## Learning Path

1. [Big O Notation](./big-o-notation.md) — Asymptotic analysis, time and space complexity, and amortized analysis
2. [Hash Tables](./hash-tables.md) — Hash functions, collision resolution, load factors, and real-world implementations
3. [Linked Lists](./linked-lists.md) — Singly/doubly linked lists, operations, and classic interview problems
4. [Heap](./heap.md) — Binary heaps, priority queues, heap sort, and top-K problems
5. [Queue](./queue.md) — FIFO queues, deques, circular buffers, and BFS applications
6. [Ring Buffer](./ring-buffer.md) — Circular buffer implementation, producer-consumer patterns
7. [Sets](./sets.md) — Set operations, implementations, and algorithmic applications
8. [Trie](./trie.md) — Prefix trees, autocomplete, and string-based search structures
